# Provenance and Publication Boundaries

This repository began as a small public connector concept in the `tarx-ai`
organization. Its Git history was preserved when it moved to John Wantz Jr.'s
personal GitHub and was rebuilt as an independent, tested reference
architecture.

## Included

- Original public Apache-2.0 repository history
- Independently written routing, queue, subscription, and inference primitives
- Synthetic ontology data
- Links to public, primary Palantir documentation
- General architectural patterns implemented and tested in this repository

## Excluded

- A Palantir-authored document marked proprietary, confidential, and
  non-distributable
- Customer data, credentials, tenant URLs, ontology identifiers, or screenshots
- Private TARX product code and duplicated internal worktrees
- Unrelated experimental code involving payments, personal finance, or
  third-party workspaces
- Claims of employment by, partnership with, certification from, or endorsement
  by Palantir

“Palantir” and product names are used only to describe the intended integration
surface. Palantir Technologies owns its respective trademarks.
