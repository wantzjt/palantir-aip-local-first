# Contributing

Contributions that improve the reference architecture, failure-mode coverage,
or documentation accuracy are welcome.

1. Open an issue describing the behavior or design decision.
2. Keep examples synthetic and tenant-neutral.
3. Add tests for behavioral changes.
4. Run `npm run check`.
5. Use precise language: distinguish implemented behavior from production
   guidance and future work.

Do not submit confidential material, customer data, credentials, or generated
code from a private ontology.
